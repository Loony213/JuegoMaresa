DATA CHEF MARESA
================

1. Instala:
   pip install pygame pillow

2. Ejecuta:
   python data_chef_maresa_inicio.py

3. Para usar tus personajes:
   Coloca estos archivos en la carpeta assets:

   - chef.png          -> Chef principal
   - tecnologia.png    -> Personaje de Tecnología
   - rrhh.png          -> Personaje de Recursos Humanos
   - logo_maresa.png   -> Logo MARESA (opcional)

   PNG con fondo transparente es lo recomendado.

4. También puedes pulsar F2 mientras juegas:
   selecciona una tarjeta y carga una imagen desde cualquier carpeta.

La pantalla está preparada para seguir creciendo hacia el juego completo:
Mercado -> Fuentes -> Limpieza/ETL -> Refrigeradora -> Preparación -> Panel.
